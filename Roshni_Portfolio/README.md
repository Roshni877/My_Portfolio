# Roshni — Portfolio Website

A single-file, cinematic personal portfolio built from your resume content.

## How to use
1. Unzip this folder.
2. Double-click `index.html` to open it directly in any browser — no install needed.
3. To go live: drag the folder into [Netlify Drop](https://app.netlify.com/drop) or upload to GitHub Pages.

## Customize
- Replace `resume.pdf` with your real resume (keep the same filename so the Download button keeps working).
- Swap the gallery/profile images: search `images.unsplash.com` URLs in `index.html` and replace with your own image paths (e.g. `assets/profile.jpg`).
- Add project demo videos: open the site, go to **Projects**, click **▶ Explore Build** on any card, paste a YouTube or .mp4 link, and click **Load** — it's saved in your browser automatically.
- Update GitHub/LinkedIn/demo links inside the `projects` array near the top of the `<script>` section.
- Toggle dark/light mode with the ◐ icon in the navbar (saved automatically).
